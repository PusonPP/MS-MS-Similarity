# Data

65 MassBank records from University of Athens, release 2026.03.

Authors and license are kept in each raw file. The records state `CC BY`.
Credit: Nikiforos Alygizakis, Anna Bletsou, Nikolaos Thomaidis, University of Athens.
Use the original record headers for record-specific attribution.

The analysis reads bundled data. To restore and verify these files, run:

```bash
python3 scripts/fetch_data.py
```
